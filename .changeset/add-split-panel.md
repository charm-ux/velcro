'@charm-ux/velcro': minor
---

Add a prototype `VelcroSplitPanel`, registered as `sl-split-panel` and built on the `@charm-ux/core` base element (core has no split-panel component). It matches Shoelace 2.20.1's API member for member: the `position`, `position-in-pixels`, `vertical`, `disabled`, `primary`, `snap` (a string of pixel, percentage and `repeat()` values, or a function) and `snap-threshold` properties, the `start`, `end` and `divider` slots, the `start`, `end`, `panel` and `divider` parts, the `--divider-width`, `--divider-hit-area`, `--min` and `--max` custom properties, and the bubbling, composed `sl-reposition` event. Dragging with the mouse or touch, the keyboard (arrows, Shift, Home, End, Enter to collapse), snapping, the primary panel, `--min` / `--max`, nesting and right-to-left layout behave as in Shoelace, including its quirks, which are listed on the docs page (for example that `repeat()` reads its interval from the whole snap string, that a press alone does not move the divider, and that `sl-reposition` also fires on the first update). All 17 of Shoelace's own split panel tests pass against Velcro unmodified. The component uses Shoelace's own base styles instead of core's, so the `hidden` attribute does not hide the host (as in Shoelace), and neither core's focus outline offset nor its forced `border-box` reaches the parts. Also exports Shoelace's `SNAP_NONE` constant and the `SnapFunction` and `SnapFunctionParams` types, and dispatches core's inherited non-bubbling `ready` event, which Shoelace does not. Not implemented or unverified: a `dir` set only as a property (the attribute is read, as in the other components), `sl-icon` and `sl-select` (the docs examples use an inline svg and a native select), the Shoelace React examples, touch outside Chromium, pen input, screen reader behavior, visual parity beyond computed-style and geometry checks, and Firefox locally. Registration is browser-only. Adds the `@charm-ux/velcro/split-panel` and `@charm-ux/velcro/split-panel/class` exports, internal `drag` and `clamp` helpers, two changes to the Custom Elements Manifest configuration (a component module may export constants, and the generated React wrappers now assign every property whose attribute name is hyphenated, such as `positionInPixels` and `snapThreshold`, as an element property instead of an attribute, for all components), and updates the third-party notices for adapted Shoelace (MIT) wording, behavior, styles and vendored tests.
