Add a prototype `VelcroProgressBar`, registered as `sl-progress-bar` on top of the `@charm-ux/core` progress bar: `value` (0 to 100, default 0), `indeterminate` and `label` properties, a default slot shown inside the indicator, the `base` (`role="progressbar"`), `indicator` and `label` parts, and the `--height`, `--track-color`, `--indicator-color` and `--label-color` custom properties. The light theme gains `--sl-font-weight-normal` and `--sl-shadow-small`. Not implemented or unverified: localization of the default accessible name (fixed English "Progress"), reduced-motion handling (neither Shoelace 2.20.1 nor Velcro changes the animation), re-evaluating the right-to-left animation when only an ancestor's direction changes, visual parity beyond computed-style checks in Chromium, and a dark theme. The inherited core `max`, `meter`, `hide-label` and `help-text` properties and the core markup and parts are present but have no effect. Registration is browser-only. Adds the `@charm-ux/velcro/progress-bar` and `@charm-ux/velcro/progress-bar/class` exports and the `SlProgressBar` alias, and updates the third-party notices for adapted Shoelace (MIT) wording, structure, styles and docs examples.
