Add prototype `VelcroRadioGroup` (alias `SlRadioGroup`, registered as `sl-radio-group` on top of the `@charm-ux/core` radio group) and `VelcroRadioButton` (alias `SlRadioButton`, registered as `sl-radio-button` on the core base element, as core has no radio button), with Shoelace 2.20.1's API. The radio group has `label`, `help-text`, `name` (default `option`), `value`, `size`, `form` and `required`, the `label` and `help-text` slots, the `form-control*`, `button-group` and `button-group__base` parts, the `sl-change`, `sl-input` and `sl-invalid` events, Shoelace's selection, arrow-key and Space handling with a roving tab stop, and its form API (`validity`, `validationMessage`, `checkValidity()`, `getForm()`, `reportValidity()`, `setCustomValidity()`, `focus()`); like Shoelace's it is not form-associated and takes part in forms through their `formdata` and `submit` events. It wraps radio buttons in Velcro's `sl-button-group`, which constructing a group defines when the tag is free (the group's entry also registers it). The radio button has `value`, `disabled`, `size`, `pill` and the reflected internal `checked`, the `prefix`, default and `suffix` slots, Shoelace's button parts, `sl-focus` and `sl-blur`, and reuses Velcro's button styles. Shoelace's quirks are matched and listed on the docs pages. The radio group keeps core's `disabled`, `readonly`, `hide-label` and `error-message` as Velcro extensions that change nothing unless set; core's `layout`, `invalid` and `label-position` are accepted but inert, and `autofocus` is the platform's own property, as in Shoelace. The radio button decides which content counts as a label with Shoelace's slot rule (a new internal slot controller adapted from Shoelace's). Shoelace's radio group tests (42 pass, one is skipped by Shoelace itself) and radio button tests (2) pass in Chromium; the conformance gate now binds an upstream `it.skip` in a test file that also has generated titles when its identity is unambiguous. Adds the `@charm-ux/velcro/radio-group`, `radio-group/class`, `radio-button` and `radio-button/class` exports, the docs pages with Shoelace's examples and React ports, the `valueMissing` and `customError` validity states in the shared form helper, and the third-party notices for adapted Shoelace (MIT) wording, structure and styles. Registration is browser-only.
