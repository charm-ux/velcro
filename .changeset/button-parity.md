'@charm-ux/velcro': minor
---

Bring `sl-button` to Shoelace 2.20.1 parity: all 87 of Shoelace's own button tests now pass against Velcro (15 before), and the button entries are removed from the upstream known-failures ledger. The button now renders Shoelace's structure and styles: a `base` `<button>`, or an `<a>` when `href` is set, with `button` / `button--*` classes around the `prefix`, `label` and `suffix` slots, a `caret` part and an `sl-spinner` (`spinner` part) while `loading`. The core button styles are no longer applied. Added Shoelace API: `rel` (default `noreferrer noopener`), `download`, `title` forwarding, `form`, `formaction`, `formenctype`, `formmethod`, `formnovalidate` and `formtarget`, the `button` property, `validity`, `validationMessage`, `checkValidity()`, `reportValidity()`, `setCustomValidity()`, `getForm()` and the `sl-invalid` event. `name` and `value` now default to `''`, `type` is no longer reflected, and removing a reflected attribute restores the property's initial value, as in Shoelace. `type="submit"` and `type="reset"` now submit or reset the form through a temporary native button, so the submit event fires, constraint validation runs (unless `novalidate` / `formnovalidate`), and the button's name, value and `form*` overrides reach the submitter. This port of Shoelace's form control controller also replaces the form's `checkValidity()` / `reportValidity()` and sets `data-valid` / `data-invalid` style attributes on the button. Like Shoelace's button, the element is no longer form-associated: it is not in `form.elements` and a disabled `<fieldset>` does not disable it. Importing the `sl-button` entry (or the package root) also registers `sl-spinner`. Differences from Shoelace, documented on the docs page: a disabled link button swallows clicks, form reset does not clear the button's `value`, the caret is an inline svg (there is no `sl-icon`), and the core extras are kept as Velcro extensions (`toggle` / `pressed`, `expanded`, `current`, `autofocus`, `referrerpolicy`, `shows` / `hides` / `toggles`, the `focusable` attribute and the `ready` event). The core `icon-only` and `allow-wrap` attributes now have no effect. The docs page gains Shoelace's examples (variants, sizes, outline, pill, circle, text, links, custom width, prefix/suffix, caret, loading, disabled, styling) and a forms example. Checked in Chromium only. Updates the third-party notices for the adapted Shoelace (MIT) button styles, component and form controller.
