Add a prototype `VelcroPopup`, registered as `sl-popup` on the `@charm-ux/core` base element: Shoelace 2.20.1's popup API (`anchor` as an id, element, `anchor` slot or virtual element, `active`, the twelve `placement` values, `strategy`, `distance`, `skidding`, `arrow`, `arrow-placement`, `arrow-padding`, `flip` with its fallback placements, strategy, boundary and padding, `shift`, `auto-size`, `sync` and `hover-bridge`), the `reposition()` method, the `sl-reposition` event, the `popup`, `arrow` and `hover-bridge` parts and the arrow and auto-size custom properties. It does not extend the core popup, a dismissible surface whose `anchor`, `placement` and `reposition()` types cannot be replaced with Shoelace's in a subclass; it positions through the core popup's own Floating UI calls instead, so no Floating UI dependency is added. Shoelace's quirks are matched (`sl-reposition` fires before the new position is applied, the arrow's default color differs from its documented default, a string `flipFallbackPlacements` property is not split, and removing `placement` or `strategy` restores the recorded value). Not implemented or unverified: the composed-offset-position offset-parent polyfill Shoelace uses for the `absolute` strategy (Floating UI's default lookup is used; a popup slotted into a shadow tree with a positioned element between the slot and the host was not tested), a `dir` set only as a property, other browsers, transformed or zoomed containers, and the Shoelace examples that need `sl-select`, `sl-input`, `sl-switch` or `sl-range` (ported with native controls) or are React. Inherits the core `dir` property and `ready` event. Adds the `@charm-ux/velcro/popup` and `@charm-ux/velcro/popup/class` exports (with the `SlPopup` alias) and updates the third-party notices for adapted Shoelace (MIT) wording, behavior and styles.
