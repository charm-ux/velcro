'@charm-ux/velcro': minor

Add prototype `VelcroBadge` and `VelcroDivider`, registered as `sl-badge` and `sl-divider` through the native registration helper on top of the `@charm-ux/core` badge and divider. The badge has the `variant` (`primary`, `success`, `neutral`, `warning`, `danger`), `pill` and `pulse` properties, a default slot and a `base` part with `role="status"`. The divider has the `vertical` property, sets `role="separator"` and keeps `aria-orientation` in sync, and has the `--color`, `--width` and `--spacing` custom properties. Both read Shoelace-named tokens, so the light theme must be loaded; it gains `--sl-color-neutral-200`, `--sl-border-radius-small`, `--sl-letter-spacing-normal`, `--sl-panel-border-color` and `--sl-panel-border-width`. They are defined as the exported classes themselves through the native registry, like `sl-button` and `sl-spinner`, so importing the package root (all four components) does not change core's prefix, project configuration or scope maps; this is checked in Chromium. There is no class-only subpath or `Sl*` alias for them yet. Not implemented or unverified: the core `--badge-*` / `--divider-*` properties, the core divider `orientation`, `presentation`, `inset` and `align-content` and the core markup and parts (inherited but with no effect), reduced-motion handling of the badge pulse (neither Shoelace 2.20.1 nor Velcro changes it), screen reader announcements, visual parity beyond computed-style checks in Chromium, other browsers, RTL, localization and a dark theme. Adds the `@charm-ux/velcro/badge` and `@charm-ux/velcro/divider` exports and updates the third-party notices for adapted Shoelace (MIT) wording, structure and styles.
