Add `<sl-alert>`, with Shoelace 2.20.1's alert contract (exports `./alert` and `./alert/class`): `open`, `closable`, `variant`, `duration` and `countdown`; `show()`, `hide()` and `toast()`; the `sl-show`, `sl-after-show`, `sl-hide` and `sl-after-hide` events; the `icon` and default slots; the `base`, `icon`, `message`, `close-button` and `close-button__base` parts; and the `alert.show` / `alert.hide` animations from the animation registry. The close button is Velcro's `<sl-icon-button>` with the localized `close` label; constructing an alert defines it when the tag is free, with Shoelace's version-mismatch warning when another constructor of a different version owns it. Shoelace's quirks are matched and listed on the docs page (for example, an alert written in markup with `open`, a finite `duration` and `countdown` does not render). Velcro extensions kept from the core alert: `toggle()` works; `dismissible`, `closeLabel`, `heading` and `politeness` are accepted without effect; the core alert events are never emitted and the inherited `ready` event remains. The `dir` read type stays core's `'ltr' | 'rtl' | 'auto'` (the setter accepts any string). Both themes now include Shoelace's `_utility.css` rules (the toast stack and scroll lock), as Shoelace's built themes do, so toasts are positioned. Adds the third-party notice for the adapted Shoelace (MIT) code.
