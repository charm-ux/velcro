Add Shoelace 2.20.1's localization. A Velcro-local module (`src/internal/localize.ts`, adapted from `@shoelace-style/localize` 3.2.1, which is not a dependency) provides `registerTranslation` and a reactive `LocalizeController` with `term`, `exists`, `lang`, `dir`, `date`, `number` and `relativeTime`. `src/utilities/localize.ts` mirrors Shoelace's module of the same name: the `Translation` term list, English registered as the default and fallback language, and the re-export of `registerTranslation`. All 29 of Shoelace's translation modules are vendored in `src/translations/` with a hash manifest. 21 are unmodified; in 8 (ar, cs, en, fi, hr, id, it, sl), the one import from `@shoelace-style/localize` points at Velcro's module instead. `sl-spinner` ("loading"), `sl-progress-bar` and `sl-progress-ring` ("progress", when `label` is empty) and `sl-split-panel` (the divider's "resize") now render their accessible names from the registry, as Shoelace does. Terms resolve from the element's `lang`, then the document's, by region, then by base language, then English. Components re-render when a translation is registered or the document's `lang` / `dir` changes. As upstream, the document's `lang` and `dir` are read from a snapshot that its `<html>` observer (attached when the module loads) and each registration refresh. The spinner, progress bar and progress ring now declare `lang` as a reactive property like Shoelace's base element (undefined by default). The progress bar's right-to-left animation now follows its own `dir` attribute, then the document's, as in Shoelace (previously the computed direction). The format components share the same controller. The package marks `dist/utilities/localize.js` and `dist/translations/*.js` as having side effects. A Localization docs page covers usage, resolution, differences and the upstream quirks matched (for example, the first registered translation is the fallback). New package exports, by exact key with no wildcard: `@charm-ux/velcro/utilities/localize` (`registerTranslation`, the `Translation` type and the `LocalizeController`) and `@charm-ux/velcro/translations/<code>` for each of Shoelace's 29 translation files (ar, cs, da, de, de-ch, en, en-gb, es, fa, fi, fr, he, hr, hu, id, it, ja, nb, nl, nn, pl, pt, ru, sl, sv, tr, uk, zh-cn, zh-tw). A page that registers no translation renders English. Checked in Chromium only. Updates the third-party notices.
