Add `<sl-tree>` and `<sl-tree-item>`, with Shoelace 2.20.1's tree and tree item contracts (exports `./tree`, `./tree/class`, `./tree-item` and `./tree-item/class`). The tree: `selection` (`single`, `multiple` or `leaf`), the `sl-selection-change` event (detail `{ selection }`), the `expand-icon` and `collapse-icon` slots (cloned into every item), the `--indent-size` and `--indent-guide-*` custom properties, the click, mouse down and keyboard handling (arrows, Home, End, Enter and Space), the roving tabindex and the checkbox synchronization for multiple selection. The tree item: `expanded`, `selected`, `disabled` and `lazy`, `getChildrenItems()`, the `sl-expand`, `sl-after-expand`, `sl-collapse`, `sl-after-collapse`, `sl-lazy-change` and `sl-lazy-load` events, Shoelace's slots and parts, and the `tree-item.expand` / `tree-item.collapse` animations from the animation registry. Both are built on the `@charm-ux/core` base element (core has no tree). The tree item renders Velcro's `<sl-checkbox>`, `<sl-icon>` and `<sl-spinner>` and defines them when it is constructed and the tags are free; as in Shoelace, the tree has no dependencies and `<sl-tree-item>` is registered by its own entry. Shoelace's quirks are matched and listed on the docs pages (for example, ArrowRight and ArrowLeft move focus to the next and previous item instead of stopping at an end node or going to the parent, Enter on a non-item element inside the tree throws a TypeError, a lazy load that ends after a collapse still expands the item, and the default `--indent-size` is the large spacing token although the documented default is the medium one). The `dir` read type stays core's `'ltr' | 'rtl' | 'auto'` (the setter accepts any string). Adds the third-party notices for the adapted Shoelace (MIT) code.
