Add a prototype `VelcroRelativeTime`, registered as `sl-relative-time` on the `@charm-ux/core` base element (there is no core relative-time): `date`, `format` (`long`, `short`, `narrow`), `numeric` (`auto`, `always`) and `sync` properties, and `lang` for the formatting locale. It renders a `time` element with an ISO `datetime` attribute and a phrase from `Intl.RelativeTimeFormat` (reusing the shared localization controller unchanged), and with `sync` re-renders on a timer. Like Shoelace it has no slots, parts, custom properties or ARIA role and does not reflect its properties. Divergences: removing the `date`, `format` or `numeric` attribute restores the default (Shoelace restores only reflected properties), a reconnected element with `sync` resumes syncing, and it inherits the core `ready` event. Not implemented or unverified: other browsers, RTL, and the Shoelace React examples. Adds the `@charm-ux/velcro/relative-time` and `@charm-ux/velcro/relative-time/class` exports and updates the third-party notices.
