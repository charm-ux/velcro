Add a prototype `VelcroIconButton` (alias `SlIconButton`), registered as `sl-icon-button`, with Shoelace 2.20.1's API: the `name`, `library`, `src`, `href`, `target`, `download`, `label` and `disabled` properties (only `disabled` reflects), the `click()`, `focus()` and `blur()` methods, the bubbling, composed `sl-focus` and `sl-blur` events and the `base` part. Core has no icon button, so it is built on the `@charm-ux/core` base element and takes Shoelace's markup and styles: a `base` part that is a `<button>`, or an `<a>` when `href` is set (with `rel="noreferrer noopener"` when `target` is set), around an aria-hidden `<sl-icon>`. The registering entry registers Velcro's `sl-icon` too, and, as with Shoelace's declared dependencies, constructing an icon button defines Velcro's `sl-icon` when that tag is not defined yet, so the class-only entry needs no extra step (an `sl-icon` another constructor owns is left in place, without Shoelace's version-mismatch warning). Shoelace's behavior is matched including its quirks (listed on the docs page under "Upstream quirks matched"): the `hidden` attribute does not hide the icon button (core's base styles, which would hide it, are replaced by Shoelace's), `click()`, `focus()` and `blur()` throw a `TypeError` before the first render, an icon button without a label is a button with an empty accessible name, a disabled link is neither disabled nor drawn as disabled (it only gets `aria-disabled`, `tabindex="-1"` and a cancelled click), and `button` is typed `HTMLButtonElement | HTMLLinkElement`. The core `ready` event is kept and labelled as a Velcro extension; `dir` and `lang` are declared as Shoelace's base element declares them (the `dir` read type stays core's `'ltr' | 'rtl' | 'auto'`). The docs examples (HTML and React) are Shoelace's, except that the "Icon Button with Tooltip" example is shown as source only because Velcro has no `sl-tooltip` yet. Not implemented or unverified: `sl-tooltip`, the dark theme, right-to-left text, color contrast, and assistive technology (the accessibility-tree check is Playwright's ARIA snapshot, computed from the DOM). Registration is browser-only. Adds the `@charm-ux/velcro/icon-button` and `@charm-ux/velcro/icon-button/class` exports, the vendored Shoelace test file to the conformance suite, and updates the third-party notices for adapted Shoelace (MIT) wording, structure and styles.
