'@charm-ux/velcro': minor

Add a prototype `VelcroMutationObserver`, registered as `sl-mutation-observer` and built on the `@charm-ux/core` base element (core has no mutation-observer component): a `display: contents` host with a default slot that observes the host and its subtree with a `MutationObserver` and emits the bubbling, composed `sl-mutation` event with `detail.mutationList`. Reflected properties `attr`, `attr-old-value`, `char-data`, `char-data-old-value`, `child-list` and `disabled` match Shoelace 2.20.1. Also dispatches core's inherited non-bubbling `ready` event, which Shoelace does not, and core's hidden-attribute rule hides the element. Documented fixes of Shoelace behavior: changing any of the five options after the first update restarts the observer (Shoelace's watchers for `attr-old-value`, `char-data` and `char-data-old-value` never fire), a disabled observer stays stopped when an option changes, and nothing is observed while the element is disconnected. Not implemented or unverified: the Shoelace React examples, assistive-technology behavior (the element has no role), and a dark theme. Registration is browser-only. Adds the `@charm-ux/velcro/mutation-observer` and `@charm-ux/velcro/mutation-observer/class` exports, the vendored Shoelace test file to the conformance suite, and updates the third-party notices for adapted Shoelace (MIT) wording, behavior and styles.
