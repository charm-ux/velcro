Add a prototype `VelcroMutationObserver`, registered as `sl-mutation-observer` and built on the `@charm-ux/core` base element (core has no mutation-observer component): a `display: contents` host with a default slot that observes the host and its subtree with a `MutationObserver` and emits the bubbling, composed `sl-mutation` event with `detail.mutationList`. Reflected properties `attr`, `attr-old-value`, `char-data`, `char-data-old-value`, `child-list` and `disabled` match Shoelace 2.20.1, and so does its behavior, including its quirks (listed on the docs page under "Upstream quirks matched"): only `attr` and `child-list` restart the observer after the first update, a restart ignores `disabled` and whether the element is connected, a reconnect stacks a second observer, and a removed `attr` attribute is restored only if it was recorded first. Core's base styles are replaced by Shoelace's own, so the `hidden` attribute renders as in Shoelace. Also has core's inherited `dir` property and non-bubbling `ready` event, which Shoelace's manifest for this component does not list. Not implemented or unverified: the Shoelace React examples, assistive-technology behavior (the element has no role), and the examples' appearance under the dark theme (the component itself has no theme tokens and works with both themes). Registration is browser-only. Adds the `@charm-ux/velcro/mutation-observer` and `@charm-ux/velcro/mutation-observer/class` exports, the vendored Shoelace test file to the conformance suite, and updates the third-party notices for adapted Shoelace (MIT) wording, behavior and styles.
